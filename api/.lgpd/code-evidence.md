## Divergências da documentação interna

`docs/auth-known-limitations.md:19` afirma inexistência de limitação por IP/e-mail: contradiz `routes.go:32-37` e testes de rate limit. A ausência de limite do corpo ainda procede. Atualizar a descrição para refletir o código e manter as limitações de proxy/cache, sem declarar controles de produção verificados.
