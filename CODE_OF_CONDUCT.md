# Código de Conduta

## Nosso compromisso

Participantes do Versum devem tratar outras pessoas com respeito. Comentários,
issues, pull requests e discussões devem se concentrar no trabalho e acolher
pessoas com diferentes experiências, origens e crenças.

Não são aceitos ataques pessoais, assédio, discriminação, publicação de dados
pessoais ou conduta que prejudique a colaboração.

## Aplicação

Mantenedores podem editar, remover ou rejeitar contribuições que não sigam este
código. Para relatar uma situação, use o contato privado disponível no perfil do
proprietário do repositório. Não publique detalhes sensíveis em issues.
